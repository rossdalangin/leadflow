# LeadFlow Pro UI Wireframe Guide

## 1. Dashboard (Main Command Center)
- **Top Row:** 4-5 KPI Cards (Leads, Active Campaigns, Open Rate, Pipeline Value).
- **Middle Row:** Two columns. Left (2/3): Bar chart of Leads by Status. Right (1/3): Growth Forecast widget.
- **Bottom Row:** Recent Activity Table (Timeline of emails sent, replies received).

## 2. Lead CRM
- **Toggle View:** Switch between 'Table' and 'Kanban'.
- **Kanban Board:** 7 columns (New → Closed). Each card shows Lead Name, Score, and simple metadata. Drag-and-drop enabled.
- **Lead Detail Modal:** Sliding panel or centered modal. Split into 'Communication Thread' (left) and 'Audit Insights' (right).

## 3. Discovery Engine
- **Source Selection:** Tabs for Google, LinkedIn, Facebook.
- **Search Bar:** Prominent indigo search bar with keyword and location inputs.
- **Results Table:** Live-populated list of found businesses with 'Import' buttons.

## 4. Campaigns
- **Campaign List:** Simple list of active sequences.
- **Builder UI:** Vertical timeline. Each 'Step' is a card with Delay, Template Selector, and AI Writing triggers.

## 5. Settings
- **Tabbed Layout:** General, SMTP/Email, AI, License, Status.
- **Status Tab:** System health check (PHP version, IMAP extension, API connectivity status).

---
*Style Guide: Uses Indigo (#6366f1) as primary, Slate (#1e293b) as background, and White for cards.*
