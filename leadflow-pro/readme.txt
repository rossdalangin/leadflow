The All-in-One Autonomous Lead Generation & CRM engine for freelancers and agencies.

== Description ==

LeadFlow Pro turns your WordPress site into a fully autonomous prospecting machine. Stop manually searching for leads and start closing with data-driven AI outreach.

**Key Feature Modules:**

*   **Lead Discovery Engine:** Search Google Places, LinkedIn, and Facebook simultaneously.
*   **Smart Website Auditor:** Automatically extract technical hooks (SSL, speed, CMS) to use in your sales pitch.
*   **Built-in CRM:** Manage your pipeline with Kanban views and automated lead scoring.
*   **AI Outreach Assistant:** Let GPT-4o or Google Gemini write your emails and handle follow-ups.
*   **Multi-Step Sequences:** Build outreach flows that pause automatically when a lead replies.

== Installation ==

1. Upload the `leadflow-pro` folder to the `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Follow the Setup Wizard to configure your agency identity and API keys.
