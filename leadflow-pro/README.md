# 🏆 LeadFlow Pro: The Ultimate Autonomous Lead Gen & CRM for WordPress

**Stop the manual prospecting grind. Turn your WordPress site into a fully autonomous lead generation and client acquisition machine.**

---

## 🚀 MISSION
LeadFlow Pro is a production-ready, modular WordPress plugin designed for freelancers and agencies to automate their entire sales funnel. From discovering targeted leads to AI-driven outreach and pipeline management—all inside your own dashboard.

## 🛠 CORE FEATURE MODULES
1.  **Lead Discovery Engine:** Search Google Places, LinkedIn, and Facebook Groups simultaneously.
2.  **Smart Website Auditor:** Automatically extract technical hooks (SSL, speed, design) from lead sites.
3.  **Lead CRM:** High-performance custom-table CRM with Kanban pipeline and lead scoring.
4.  **Outreach Automation:** Build multi-step sequences that send while you sleep.
5.  **Unified Email System:** SMTP + Gmail REST API sending with IMAP reply detection.
6.  **AI Outreach Assistant:** Unified adapter for GPT-4o and Gemini 1.5 Pro qualification.
7.  **Real-Time Analytics:** Beautiful Chart.js dashboards showing funnel health and ROI.
8.  **Compliance Layer:** Built-in GDPR tools and ethical scraping controls.

## 💰 WHY LEADFLOW PRO?
- **Zero Monthly Fees:** Own your lead data and outreach engine.
- **Data Sovereignty:** All leads live on *your* server, encrypted and secure.
- **AI-Driven Logic:** Use the latest LLMs to write better emails and score intent.
- **Enterprise Ready:** Architected with custom DB tables for high-volume performance.
